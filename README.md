# Parking Environment Demo / 泊车环境演示包

This repository hosts a self-contained parking environment package intended for coursework submission. The
codebase now favors a lightweight `pip install -e .` workflow so graders can set it up quickly without Conda. A
minimal Conda/Mamba environment is still provided for convenience.

本仓库提供可独立提交的泊车环境演示包，默认采用 `pip install -e .` 安装流程，助教无需再花时间创建
沉重的 Conda 环境（仍保留可选的 Conda/Mamba 配置）。

---

## Quick Start (pip)

```bash
git clone https://github.com/Ansatz7/ME5418-parking-demo.git
cd ME5418-parking-demo

# optional: create a clean virtualenv (Python 3.8–3.12 recommended)
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

python -m pip install --upgrade pip
pip install -e .

# smoke test
parking-gym-demo --mode random --episodes 1 --max-steps 400
```

- `parking-gym-demo` is registered via `setup.py` and runs `parking_project_submission.gym_demo:main`.
- Without flags it launches manual mode for 1 episode with `max_steps=4000` using the default config.
- The default configuration is `parking_project_submission/configs/demo_default.json`, matching the curated
  notebook settings (30 m field, 24 lidar rays, bilingual notes preserved).
- Add `--mode manual` for keyboard driving, `--config path/to/custom.json` to load a different scenario, and
  `--no-visualize` to disable Matplotlib rendering in headless runs.

### Optional installers

- **uv:** `uv pip install -e .` (works inside any venv, fastest dependency resolver).
- **mamba:** `mamba env create -f environment.yml && conda activate parking-rl` if you still prefer Conda-style
  workflows. The `environment.yml` is intentionally slim and delegates Python packages to pip.

> Before final submission, recreate the project on a fresh machine or brand-new virtual environment and follow the
> README step-by-step to ensure nothing is missing.

## Core Scripts

- `parking_project_submission.gym_demo` — runs random/manual demos, exposes all CLI flags.
- `parking_project_submission.parking_env.generate_training_config` — writes randomized map variants while
  keeping dynamics consistent with `DEFAULT_CONFIG`.
- `parking_project_submission.parking_env.assist_model_tuner` — launches the Qt-based slider UI. Requires Qt
  support; on headless servers set `QT_QPA_PLATFORM=offscreen` or use X11/Wayland forwarding.

Example commands:

```bash
# generate a new scenario
python -m parking_project_submission.parking_env.generate_training_config \
  --out parking_project_submission/configs/train_random.json

# tune steering/velocity assists and sync back to JSON
python -m parking_project_submission.parking_env.assist_model_tuner \
  --config parking_project_submission/configs/demo_default.json --sync
```

## GPU / Deep RL Notes

- The current demo depends only on CPU-friendly packages: Gymnasium 0.29.1, NumPy 1.23.5, Matplotlib 3.7.1, and
  PyTorch 2.2.2.

  exact PyTorch or CUDA wheel required (e.g., `torch==2.2.2+cu124` from the official index) rather than listing
  generic “pytorch/cuda-toolkit”.
- Neural-network training scripts will be added next week; their dependencies will be listed separately once the
  algorithm is finalized.
